# Calendrier de Formation ONG – Générateur DOCX

Script Node.js qui génère un document Word professionnel (**Calendrier de formation révisé**) pour un parcours de 15 mois orienté **profil ONG / Développement opérationnel** (MEAL Officer, Project Officer, etc.).

## Contenu du document généré

- **Profil de départ et objectifs** (15 mois)
- **Tableau de bord de suivi** (indicateurs à 6 / 12 / 15 mois)
- **4 phases structurées** :
  1. Recrutabilité (semaines 1–12) – Project DPro, Kobo, CHS/PSEA, Excel
  2. Spécialisation MEAL + 1ère pratique (13–26)
  3. Rentabilité – Proposals + Finance DPro (27–40)
  4. Différenciation & positionnement (41–60) – ALGA, ONU-Habitat, candidatures
- **Récapitulatif des coûts** (≈ 90–145 USD)
- **5 principes non négociables**
- Liens vers les ressources (PM4NGOs, DisasterReady, Microsoft Learn, etc.)
- En-tête + pied de page avec numérotation

## Prérequis

- Node.js ≥ 18
- npm
